# Заказы на самовывоз для мясных магазинов — мультитенантная PWA

Один общий билд, один проект Supabase, сколько угодно магазинов.
Магазин = `tenants/<slug>/business.json` + фотографии.

* Покупатель: каталог (кг/шт) → корзина → время выдачи (считает сервер по
  занятости столов, коптилен, камер вызревания) → заказ без регистрации →
  личная ссылка, перенос, отмена, календарь (ICS), push.
* Владелец: «Выдача сегодня», поиск заказов, статусы, взвешивание и оплата,
  блокировки ресурсов, статистика (визиты / выданные заказы / полученные
  платежи / ожидаемые выдачи — не выручка), каталог и фото, ИИ-помощник.
