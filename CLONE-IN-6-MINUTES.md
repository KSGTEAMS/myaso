# Новый магазин за 6 минут

Переодевание = один `business.json` + фотографии. Код не трогаем, прежние
магазины продолжают работать.

| Минута | Действие |
|---|---|
| 0–1 | `npm run tenant:new -- --slug myaso-na-lenina --name "Мясо на Ленина" --from rebro --timezone Asia/Yekaterinburg --accent "#D4A72C"` — копия существующего магазина как отправная точка (или без `--from` — минимальный шаблон с генерированными картинками). |
| 1–3 | Правим `tenants/myaso-na-lenina/business.json` (VS Code подсказывает поля по `tenants/business.schema.json`): название, `short_name`, акцент, адрес и телефон, часы и исключения, ресурсы (столы, коптильни), профили подготовки, категории, товары с ценой за кг/шт, шагом и минимумом, `owner.email`. |
| 3–4 | Кладём фото в `tenants/myaso-na-lenina/images/`: `hero.jpg` ≥ 1200×700, фото товаров ≥ 600×450 (имена — как в поле `image`). Иконка: `brand.icon_image` (квадрат ≥ 512) или буква `brand.icon_letter`. |
| 4 | `npm run tenant:validate -- myaso-na-lenina` — схема, ссылки, контраст акцента ≥ 3:1, часы, размеры картинок. |
| 5 | `npm run tenant:publish -- myaso-na-lenina --invite-owner --demo --deploy` — магазин в preview с демо-данными, владелец получает пароль, сайт пересобран со всеми магазинами из реестра. |
| 6 | `npm run tenant:verify -- myaso-na-lenina --site https://<домен>` — БД совпадает с JSON, API отдаёт слоты, оболочка/манифест/иконки/стартовые экраны/deep links именно этого магазина. |

Когда владелец проверил витрину: `npm run tenant:publish -- myaso-na-lenina --live`
(сервер проверит готовность и удалит демо-данные).

## Что меняется от магазина к магазину

| Через business.json | Остаётся общим |
|---|---|
| название, акцент, фон, иконка, hero, тексты | JS/CSS-бандл, service worker |
| часовой пояс, валюта, часы, праздники | схема БД, RLS, SQL-логика |
| ресурсы и профили подготовки (минуты, мин/кг, буфер) | Edge Functions |
| категории, товары, цены, шаги веса, бейджи | дизайн-система и компоненты |
| интервал выдачи, мин. время на подготовку, горизонт, дедлайн изменений | — |
| включён ли ИИ-помощник и его приветствие | — |

## Шпаргалка по профилям подготовки

```json
{ "key": "cut",   "name": "Разделка",   "base_minutes": 15, "per_kg_minutes": 5, "buffer_minutes": 10, "resources": ["table-1", "table-2"] }
{ "key": "smoke", "name": "Копчение",   "base_minutes": 1440, "per_kg_minutes": 30, "buffer_minutes": 60, "resources": ["smokehouse"] }
```

Заказ из рибая и брискета займёт **стол** на ~25 мин и **коптильню** на
сутки+, оба диапазона заканчиваются в момент выдачи. Два стола → два
одновременных заказа на одно время; третий получит «время занято».
